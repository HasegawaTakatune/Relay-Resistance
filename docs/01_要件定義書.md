## 1. プロジェクト概要

### 1.1 目的
エイリアンに侵略された地球を舞台に、プレイヤーがFPSでステージを進み、エイリアンのボスを倒して地球を救う。
プレイヤー同士は同じステージには並ばないが、同じ「ワールド」を別々のルートで攻略し、**資金（物資）を託し合う**ことで間接的に協力する。

### 1.2 タイトルコンセプト
- 「Relay（リレー・託す）」＋「Resistance（抵抗軍）」
- バトンを繋ぎながら抗戦する共闘感を核とする。

### 1.3 コアとなる体験
1. 敵を倒して資金を稼ぐ。
2. 資金を自分の強化だけでなく、**他プレイヤーのための支援**（物資・援護攻撃・拠点・共有資金）にも使う。
3. プレイしていない時間もワールドは動き続け、エイリアンが制圧範囲を広げる。放置するほど難しくなる。
4. 誰か1人がボスを倒せばワールド全体がクリアになる。貢献は経歴・勲章・階級として残る。

## 3. 用語定義

| 用語 | 定義 |
|---|---|
| ワールド | 1つの侵略状況を共有するゲーム世界。複数プレイヤーが参加できる。ボス撃破でクリア、作戦期間の終了でリセット |
| 作戦期間 | マルチワールドを遊べる期間。ワールドを作成してから30日間。ワールドごとに異なる |
| リザルト期間 | 作戦期間が終わった後（またはクリアした後）の1週間。ワールドが削除されるまでの期間で、遊べず、結果の確認・グッドだけができる |
| ワープ | 制圧済みの拠点（途中拠点・制圧した敵拠点の跡など）へ移動して出撃すること。ワールド内のどのルートの拠点にも行ける |
| ワールド枠 | 同時に存在できる作戦期間中のマルチワールドの上限（100個） |
| ルート | ワールド内の攻略経路。初期スポーン地点からボスエリアまでのエリアの並び。分岐と合流を含む |
| エリア | ルートを区切った単位。エリア内のエイリアンを全滅させると「制圧」となる |
| ステージ | プレイヤー1人がプレイする3D空間。1ステージには1人のプレイヤーのみ（同じエリアにいる他プレイヤーは表示・同期される） |
| 最前線 | プレイヤー側の制圧済みエリアと、エイリアン側のエリアとの境目 |
| 初期スポーン地点 | ルートの開始地点。エイリアンに制圧されない |
| 途中拠点 | 資金で設営するリスポーン用チェックポイント |
| 敵拠点 | エイリアンの増援・物資の供給源。破壊すると増援・攻撃バリエーションが減る |
| 資金 | 敵撃破で得る通貨。各種支援・強化に使う |
| 共有資金 | 他プレイヤーに使い道を任せるために託した資金 |
| 制圧能力 | エイリアンが時間経過で前進する力 |
| 貢献度 | スコアの累計値。階級の昇格に使う |
| 勲章 | 貢献内容に応じて得るコレクション要素 |

## 4. 機能要件

### 4.1 ゲームモード

| ID | 要件 |
|---|---|
| FR-MODE-01 | ソロモードとマルチモードを用意する |
| FR-MODE-02 | ソロモードは本人専用のワールドで遊ぶ。ソロワールドでは**時間が経ってもエイリアンの侵攻は進まず**、作戦期間・リザルト期間の対象外とする（いつでも遊べ、リセットされない） |
| FR-MODE-03 | マルチモードは複数プレイヤーが1つのワールドを共有する。いずれかのプレイヤーがボスを倒すとワールドクリアとなる |
| FR-MODE-04 | ソロでもクリアできる難易度にする（基本武器のみでクリア可能） |

### 4.2 FPSプレイ

| ID | 要件 |
|---|---|
| FR-FPS-01 | 一人称視点で移動・射撃・リロード・武器切替ができる |
| FR-FPS-02 | 基本武器（ハンドガン）は弾数無限とする |
| FR-FPS-03 | プレイヤーは体力とスタミナを持つ |
| FR-FPS-04 | キャラクター・敵・アイテムは2Dビルボードで描画し、カメラとの向きに応じて前面・背面のテクスチャを切り替える |
| FR-FPS-05 | 残機は無制限とする |

### 4.3 ワールド・エリア・制圧

| ID | 要件 |
|---|---|
| FR-WLD-01 | ワールドは複数のルートを持ち、プレイヤーはランダムにルートへ割り当てられる。人数が多い場合は同じルートに割り当てられることがある |
| FR-WLD-02 | ルートは複数エリアで構成され、途中に分岐がある。分岐は必ず1か所に合流する |
| FR-WLD-03 | 分岐先には敵拠点がある場合とない場合がある。拠点がない分岐先は敵が少ない |
| FR-WLD-04 | エリア内のエイリアンを全滅させるとエリア制圧となる |
| FR-WLD-05 | 制圧は最前線から順に進む。飛び地（虫食い状）の制圧はできない |
| FR-WLD-06 | エリアを制圧しなくても先へ進める。戦わずにボスエリアまで行けるが、その場合は後方から常にエイリアンの増援が来る |
| FR-WLD-07 | ボスエリアまで制圧するとエイリアンの増援が止まり、ボスに倒されてもボスエリア近くで復活できる |
| FR-WLD-08 | 分岐の合流時に、もう片方の分岐でエイリアンの制圧エリアが孤立した場合、放置するとボス方向と初期スポーン地点方向の両方へエイリアンが進行する |
| FR-WLD-09 | （マルチのみ）誰も遊んでいなくてもワールドの状況は時間とともに変化する |
| FR-WLD-10 | （マルチのみ）全プレイヤーが遊ばない状態が続くと、プレイヤーが制圧した箇所もエイリアンが徐々に取り返す |
| FR-WLD-11 | 初期スポーン地点はエイリアンに制圧されない |
| FR-WLD-12 | マルチワールドは、**作成してから30日間**を作戦期間（遊べる期間）とする。30日が過ぎるまでにボスが倒されなければ、地球が侵略されたとみなしてワールドをリセットする |
| FR-WLD-15 | 作戦期間が終わった（またはクリアした）ワールドはリザルト期間となり、プレイ（出撃・資金の使用）ができない。結果・戦歴・貢献者一覧の確認と、グッドだけができる |
| FR-WLD-16 | マルチワールドは、日時に関係なくいつでもプレイヤーが作成できる |
| FR-WLD-17 | 作戦期間中のマルチワールドは、同時に**100個まで**とする。クリア・失敗したワールドは数えない。上限に達している間は新しく作成できない |
| FR-WLD-18 | 1人のプレイヤーが作成できる作戦期間中のマルチワールドは1個までとする。作成したワールドがクリア、または失敗（陥落）で終わると、再び作成できるようになる |
| FR-WLD-19 | 1つのマルチワールドに参加できるのは**20人まで**とする |
| FR-WLD-20 | ワールドの参加者は、ワールド内の**制圧済みの拠点へワープ**できる。自分に割り当てられたルート以外の拠点へもワープできる。このため、プレイヤーの多くは最前線とその先に集中する想定とする |
| FR-WLD-13 | ワールドをリセットすると、エイリアンの制圧状況・強化状況もリセットされる |
| FR-WLD-14 | クリア・失敗（陥落）したワールドは、どちらも**1週間のリザルト期間**の後、ワールドごと削除する。プロフィールの累計貢献度・階級・勲章は削除後も残る |

### 4.4 エイリアン

| ID | 要件 |
|---|---|
| FR-ALN-01 | （マルチのみ）ワールド生成から1週間ごとにエイリアンが強化される（倍率は機能仕様書を参照） |
| FR-ALN-02 | （マルチのみ）4時間ごとに「5m × 制圧能力倍率」の距離だけエイリアンが前進する |
| FR-ALN-03 | 前進した先にプレイヤー側の施設（途中拠点など）があれば、施設もエイリアンに制圧される |
| FR-ALN-04 | エイリアンに制圧された途中拠点は、エイリアンのリスポーン地点になる |
| FR-ALN-05 | 敵拠点を破壊しても、そのエリアを制圧しなければ拠点は修復される |
| FR-ALN-06 | 敵拠点の物資が減ると攻撃バリエーションが減り、牽制射撃の頻度が下がる、または牽制射撃をしなくなる |
| FR-ALN-07 | エイリアンのボスが存在し、倒すとワールドクリアとなる |

### 4.5 資金と使い道

| ID | 要件 |
|---|---|
| FR-FND-01 | 敵を倒すと資金が得られる |
| FR-FND-02 | 資金は次の用途に使える：物資調達／援護攻撃要請／共有資金／プレイヤー強化／途中拠点設営／敵拠点攻撃要請 |
| FR-FND-03 | **物資調達**：弾薬・回復物資を所定の地点に置く。投入額によって物資の量が変わる |
| FR-FND-04 | **援護攻撃要請**：上空からの爆撃、またはタレット展開を行う。投入額によって攻撃範囲と威力が変わる |
| FR-FND-05 | **共有資金**：他プレイヤーに使い道を任せるために資金を託す。共有資金は、同じワールドの誰でも、どの用途（プレイヤー強化を含む）にも自由に使える |
| FR-FND-06 | **プレイヤー強化**：体力・スタミナ・武器性能を強化する。武器の攻撃力は上がらないか、ごくわずかしか上がらない |
| FR-FND-07 | **途中拠点設営**：力尽きたときの再出撃地点を作る |
| FR-FND-08 | **敵拠点攻撃要請**：敵拠点を攻撃し、増援と物資を減らす |
| FR-FND-09 | プレイヤー強化以外の用途は、他プレイヤーにも効果が及ぶ |
| FR-FND-10 | プレイヤー強化の状況は、ワールドをクリアした場合に限り次のワールドへ引き継がれる |
| FR-FND-11 | 資金はリアルタイムで同期する |

### 4.6 リスポーン

| ID | 要件 |
|---|---|
| FR-RSP-01 | 力尽きたときは、有効な途中拠点または初期スポーン地点から再出撃できる |
| FR-RSP-02 | 途中拠点が制圧された場合でも、初期スポーン地点から復活できる |
| FR-RSP-03 | ボスエリアまで制圧済みの場合は、ボスエリア近くで復活できる |
| FR-RSP-04 | 出撃・再出撃のときに、ワープできる拠点（FR-WLD-20）を出撃地点として選べる |

### 4.7 スコア・貢献・評価

| ID | 要件 |
|---|---|
| FR-SCR-01 | 資金貢献・敵拠点制圧・敵キル数からスコアを算出する |
| FR-SCR-02 | スコアへの重みは「資金貢献 ＞ 敵拠点制圧 ＞ 敵キル数」とする |
| FR-SCR-03 | 援護攻撃による敵キル数は、通常のキル数とは別に数える |
| FR-SCR-04 | 貢献度に応じて勲章（コレクション要素）を与える |
| FR-SCR-05 | 貢献度は累計され、一定値に達すると階級が上がる |
| FR-SCR-06 | 階級は陸軍の階級（参考：[MAMOR-WEB「階級」の始まりと呼び名の由来](https://mamor-web.jp/_ct/17734119) の「アメリカ陸軍」の表）に従い、次の順とする（全22階級）。<br>2等兵 ＜ 1等兵 ＜ 上等兵 ＜ 伍長 ＜ 3等軍曹 ＜ 2等軍曹 ＜ 1等軍曹 ＜ 曹長 ＜ 上級曹長 ＜ 准尉 ＜ 上級准尉 ＜ 少尉 ＜ 中尉 ＜ 大尉 ＜ 少佐 ＜ 中佐 ＜ 大佐 ＜ 准将 ＜ 少将 ＜ 中将 ＜ 大将 ＜ 元帥<br>※ 表にある「候補生」は士官候補生という立場であり、昇格の段階には含めない |
| FR-SCR-07 | 資金貢献・敵拠点制圧の状況を、ワールドごとに経歴風にまとめる |
| FR-SCR-08 | ワールドごとに貢献者（プレイヤー名）を貢献内容と一緒に一覧表示する |
| FR-SCR-09 | 他のプレイヤーに対してのみグッドボタンを押して称賛できる（自分には押せない） |

### 4.8 プレイヤーステータス

| ID | 要件 |
|---|---|
| FR-PLY-01 | 次の項目を表示する：アイコン画像／プレイヤー名／階級／獲得勲章一覧／キャラクター育成度／累計貢献度／グッド数 |

### 4.9 同期

| ID | 要件 |
|---|---|
| FR-SYN-01 | 別ルート・別エリアにいるプレイヤーの情報は同期しない |
| FR-SYN-02 | 同じエリアにいるプレイヤー同士は、座標と敵撃破を同期する |
| FR-SYN-03 | 敵の位置や行動は同期しない。敵が倒されたとき、各プレイヤーの画面で敵の数が減るだけとする |

## 5. 非機能要件

| ID | 区分 | 要件 |
|---|---|---|
| NFR-01 | 性能 | WebGL上で目標30fps以上（推奨60fps）【要確認：対象PCスペック】 |
| NFR-02 | 容量 | unityroomのアップロード容量制限に収まること。テクスチャは圧縮し、2D素材を中心にする |
| NFR-03 | 通信 | 座標同期は同じエリア内だけで行い、送信頻度を抑える（目安：4Hz。無料枠のメッセージ数に収める） |
| NFR-04 | 通信 | 資金の変化は1秒以内に他プレイヤーへ反映する |
| NFR-05 | 可用性 | サーバーとの通信が切れてもステージのプレイは続けられ、再接続後に結果を送り直せること |
| NFR-06 | 整合性 | ワールドの状態（制圧・強化・リセット）はサーバーを正とし、クライアントの時計に依存しない |
| NFR-07 | 不正対策 | 資金の増減・スコアはサーバー側で検証する（単位時間あたりの獲得上限など） |
| NFR-08 | セキュリティ | Supabase の Row Level Security（RLS）で、プレイヤーは自分のデータだけを書き換えられるようにする |
| NFR-09 | データ保持 | クリア（または陥落）後のワールドは1週間保存し、その後自動削除する |
| NFR-10 | 拡張性 | エイリアンの強化倍率・制圧速度・価格などのバランス値はサーバー側の設定で変えられること |
| NFR-11 | 対応言語 | 日本語【要確認：多言語対応の有無】 |
| NFR-12 | 入力 | キーボード＋マウス【要確認：ゲームパッド・スマホ対応の有無】 |

## 6. プレイ時間の想定

| 条件 | 想定クリア時間 |
|---|---|
| 複数人で協力して物資を分け合う場合 | 約1時間〜 |
| 作成したばかりのマルチワールドを1人で攻略する場合 | 約1時間 |
| ソロモード | 約1時間（侵攻が進まないため、プレイの間隔が空いても難易度は変わらない） |
| 侵略が進んだマルチワールド | 最長で作戦期間の終わり（作成から30日）まで |

マルチワールドでは、時間が経つほどエイリアンが強くなり制圧範囲も広がるため、放置するほど難易度は自動的に上がる。

### 9.1 決定事項

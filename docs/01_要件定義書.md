## 1. プロジェクト概要

### 1.1 目的
エイリアンに侵略された地球を舞台に、プレイヤーがFPS視点でステージを進み、エイリアンのボス（クイーン）を倒して地球を救う。
プレイヤーは同じ「ワールド」で戦うが、別々の「ルート」で戦うことがほとんどである。ただし、招待やプレイヤー数が多い場合はルートがランダムに割り振られるため、同じルートで一緒に戦うことがある。
プレイヤー同士は、**資金（物資）を託し合う**ことで間接的に協力する。

### 1.2 タイトルコンセプト
- 「Relay（リレー・託す）」＋「Resistance（抵抗軍）」
- バトンを繋ぎながら抗戦する共闘感を核とする。

### 1.3 コアとなる体験
1. 敵を倒して資金を稼ぐ。
2. 資金を自分の強化だけでなく、**他プレイヤーのための支援**（物資・援護攻撃・拠点・共有資金）にも使う。
3. プレイしていない時間もワールドは動き続け、エイリアンが制圧範囲を広げる。放置するほど難しくなる。
4. 誰か1人がクイーンを倒せばワールド全体がクリアになる。貢献は経歴・勲章・階級として残る。
5. マルチワールドをクリアするとポイントを獲得でき、スキンやスキルを解放するやりこみ要素に使える。

## 3. 用語定義

| 用語 | 定義 |
|---|---|
| ワールド | 1つの侵略状況を共有するゲーム世界。複数プレイヤーが参加できる。クイーン撃破でクリア、作戦期間の終了でリセット |
| 作戦期間 | マルチワールドを遊べる期間。ワールドを作成してから30日間。ワールドごとに異なる |
| リザルト期間 | 作戦期間が終わった後（またはクリアした後）の1週間。ワールドが削除されるまでの期間で、遊べず、結果の確認・グッドだけができる |
| ワープ（ファストトラベル） | 制圧済みの拠点（制圧した敵拠点・初期スポーン地点）へ移動して出撃すること。ワールド内のどのルートの拠点にも行ける。飛び地の制圧や、新しく参加したプレイヤーの移動に時間がかかり過ぎないようにするための仕組み。設定（有効・無効、詠唱時間など）を変えられる |
| ワールド枠 | 同時に存在できる作戦期間中のマルチワールドの上限（100個） |
| ルート | ワールド内の攻略経路。初期スポーン地点からボスエリアまでのノードの並び。分岐と合流を含む。1ワールドに最大10ルート |
| ノード | ルートを区切った単位（従来の「エリア」と同義）。ノード内のエイリアンを全滅させると制圧できる。1ルートあたり分岐を含めて30〜50個をランダム生成する |
| エリア | ノードと同義。本書では制圧の距離・数の単位としては「ノード」を使う |
| 中立エリア | エイリアンを全滅させたが、最前線から連続していないため制圧できないノード（虫食いになる場合） |
| ステージ | プレイヤーがプレイする3D空間 |
| ボスエリア | クイーンがいるノード。**ワールドに1つだけ**で、全ルートが最終的にここへ合流する。ボスエリア内だけは、ワールドの全員（最大20人）を同じ戦闘として同期する（FR-SYN-07） |
| 最前線 | プレイヤー側の制圧済みエリアと、エイリアン側のエリアとの境目 |
| 初期スポーン地点 | ルートの開始地点。エイリアンに制圧されない |
| 敵拠点 | エイリアンの増援の供給源。拠点内のエイリアンを全滅させて制圧すると増援が止まり、プレイヤーのリスポーン地点・ワープ先になる。「有効な途中拠点」とは、この制圧した敵拠点のことである（別に途中拠点は設営しない） |
| クイーン | エイリアンのボス。約10mの巨体。エイリアンと近衛兵をスポーンさせる。攻撃能力は持たない |
| 資金 | 敵撃破で得る通貨。各種支援・強化に使う |
| 共有資金 | 他プレイヤーに使い道を任せるために託した資金 |
| 制圧能力 | エイリアンが時間経過で前進する力 |
| 功績度（貢献度） | ワールドごとの「制圧した敵拠点数 × 1000 ＋ 資金貢献額 × 100」。その累計値（累計貢献度）で階級が上がる。敵のキル数は含めない |
| 勲章 | 貢献内容に応じて得るコレクション要素 |
| ポイント | マルチワールドのクリア時に、リザルトの合計功績度を100で割った値を付与される、やりこみ用の通貨。ゲーム中の育成度とは別 |
| 被害者数 | リザルトに表示する、侵略によって出た被害の推計値 |
| 戦死者数 | ワールド内で倒れたプレイヤーの数。被害者数とは別に数えてリザルトに表示する |

## 4. 機能要件

### 4.1 ゲームモード

| ID | 要件 |
|---|---|
| FR-MODE-01 | ソロモードとマルチモードを用意する |
| FR-MODE-02 | ソロモードは本人専用のワールドで遊ぶ。ソロワールドでは**時間が経ってもエイリアンの侵攻は進まず**、作戦期間・リザルト期間の対象外とする（いつでも遊べ、リセットされない） |
| FR-MODE-03 | マルチモードは複数プレイヤーが1つのワールドを共有する。いずれかのプレイヤーがクイーンを倒すとワールドクリアとなる |
| FR-MODE-04 | ソロでもクリアできる難易度にする（基本武器のみでクリア可能） |
| FR-MODE-05 | ソロモードの資金・武器・キャラクターの育成度は、マルチモードに引き継げない |
| FR-MODE-06 | ソロモードをクリアしたときの資金・武器・キャラクターの育成度は、次回のソロワールドでリセットされる |
| FR-MODE-07 | マルチモードをクリアしたとき、リザルトに応じてポイントを付与する（4.10 参照）。ただし、ワールドが侵略された（陥落した）場合、全プレイヤーはポイントを獲得できない |

### 4.2 FPSプレイ

| ID | 要件 |
|---|---|
| FR-FPS-01 | 一人称視点で移動・射撃・リロード・武器切替ができる |
| FR-FPS-02 | 基本武器（ハンドガン）は弾数無限とする |
| FR-FPS-03 | プレイヤーは体力とスタミナを持つ |
| FR-FPS-04 | キャラクター・敵・アイテムは2Dビルボードで描画し、カメラとの向きに応じて前面・背面のテクスチャを切り替える |
| FR-FPS-05 | 残機は無制限とする |
| FR-FPS-06 | ジャンプは二段まで行える |
| FR-FPS-07 | スラスター（地上・空中で使える移動補助）を使える。エネルギーを消費して使い、エネルギー量・回復速度・加速量は成長要素で増える（初期のエネルギーは3回ぶん） |
| FR-FPS-08 | スラスターのエネルギー量・回復速度・加速量は、ポイント（4.10）を使って各10段階まで強化する |
| FR-FPS-09 | 投擲武器として手榴弾・焼夷手榴弾を使える。どちらもポイントで開放する |
| FR-FPS-10 | ハンドガン以外の武器（サブマシンガン・アサルトライフル・ショットガン・ライフル）は、ポイントで開放する |

### 4.3 ワールド・エリア・制圧

| ID | 要件 |
|---|---|
| FR-WLD-01 | ワールドは最大10本のルートを持ち、プレイヤーはランダムにルートへ割り当てられる。招待やプレイヤー数が多い場合は同じルートに割り当てられることがある |
| FR-WLD-02 | ルートは複数ノードで構成され、途中に分岐がある。分岐は必ず1か所に合流する。ルートごとのノード数は、分岐を含めて30〜50の間でランダムに生成する。**全ルートの終点は、ワールドで共通の1つのボスエリアとする**（ルートはボスエリアで合流する） |
| FR-WLD-03 | 分岐先には敵拠点がある場合とない場合がある。拠点がない分岐先は敵が少ない |
| FR-WLD-04 | ノード内のエイリアンを全滅させると、そのノードは制圧または中立エリアになる（FR-WLD-05） |
| FR-WLD-05 | 制圧は最前線から順に進む。飛び地（虫食い状）の制圧はできない。飛び地でエイリアンを全滅させたノードは「中立エリア」とし、最前線が届いた時点で制圧扱いになる |
| FR-WLD-06 | エリアを制圧しなくても先へ進める。戦わずにボスエリアまで行けるが、その場合は後方から常にエイリアンの増援が来る |
| FR-WLD-07 | ボスエリアまで制圧するとエイリアンの増援が止まる。（ボスエリア付近で復活できるのは、その近くの拠点を制圧しているという構造上の結果であり、専用の復活地点は設けない） |
| FR-WLD-08 | 分岐の片方だけを制圧すると、結果としてもう片方の分岐にエイリアンの飛び地ができる。飛び地のエイリアンは、ボス方向と初期スポーン地点方向の両方へ進行し、**クイーン方向への制圧能力は通常の2倍**の速度とする |
| FR-WLD-09 | （マルチのみ）誰も遊んでいなくてもワールドの状況は時間とともに変化する |
| FR-WLD-10 | （マルチのみ）全プレイヤーが遊ばない状態が続くと、プレイヤーが制圧した箇所もエイリアンが徐々に取り返す。ボスエリア直前まで制圧していても、放置すれば順次取り返される（既存の時間経過による侵略の仕組みをそのまま使う） |
| FR-WLD-11 | 初期スポーン地点はエイリアンに制圧されない。ワールドの初期状態では、初期スポーン地点を除くすべてのノードがエイリアンに制圧されている |
| FR-WLD-12 | マルチワールドは、**作成してから30日間**を作戦期間（遊べる期間）とする。30日が過ぎるまでにクイーンが倒されなければ、地球が侵略されたとみなしてワールドをリセットする |
| FR-WLD-13 | ワールドをリセットすると、エイリアンの制圧状況・強化状況もリセットされる |
| FR-WLD-14 | クリア・失敗（陥落）したワールドは、どちらも**1週間のリザルト期間**の後、ワールドごと削除する。プロフィールの累計貢献度・階級・勲章・ポイントは削除後も残る |
| FR-WLD-15 | 作戦期間が終わった（またはクリアした）ワールドはリザルト期間となり、プレイ（出撃・資金の使用）ができない。結果・戦歴・貢献者一覧の確認と、グッドだけができる |
| FR-WLD-16 | マルチワールドは、日時に関係なくいつでもプレイヤーが作成できる |
| FR-WLD-17 | 作戦期間中のマルチワールドは、同時に**100個まで**とする。クリア・失敗したワールドは数えない。上限に達している間は新しく作成できない |
| FR-WLD-18 | 1人のプレイヤーが作成できる作戦期間中のマルチワールドは1個までとする。作成したワールドがクリア、または失敗（陥落）で終わると、再び作成できるようになる |
| FR-WLD-19 | 1つのマルチワールドに参加できるのは**20人まで**とする |
| FR-WLD-20 | ワールドの参加者は、ワールド内の**制圧済みの拠点へワープ（ファストトラベル）**できる。自分に割り当てられたルート以外の拠点へもワープできる。このため、プレイヤーの多くは最前線とその先に集中する想定とする |
| FR-WLD-24 | ファストトラベルは、飛び地の制圧への対応と、新しく参加したプレイヤーの移動時間を減らす（ゲーム体験が薄れないようにする）ために設ける。有効・無効、詠唱時間、再使用までの時間などを設定で変えられる |
| FR-WLD-21 | サーバー時間によって、エリアの背景を朝と夜に切り替える |
| FR-WLD-22 | 敵拠点は、拠点内のエイリアンを全滅させることで制圧できる。制圧した拠点からは新たにエイリアンが現れず、プレイヤーのリスポーン地点になる |
| FR-WLD-23 | 【Ph.2】ダイナミックレベリング（仮称）：全ワールドを通したクリア数・クリアにかかった時間から、新しくワールドを生成するときのレベル（難易度）を調整する。時間経過でクリア率が極端に落ちている場合は難易度を下げ、短時間でクリアが頻発している場合はレベルを上げる |

### 4.4 エイリアン

| ID | 要件 |
|---|---|
| FR-ALN-01 | （マルチのみ）ワールド生成から1週間ごとにエイリアンが強化される（倍率は機能仕様書を参照） |
| FR-ALN-02 | （マルチのみ）4時間ごとに「0.5ノード × 制圧能力倍率」だけエイリアンが前進する（旧仕様：5m × 制圧能力倍率）。端数は内部で持ち越す |
| FR-ALN-03 | 前進した先にプレイヤーが制圧した敵拠点があれば、その拠点もエイリアンに取り返される |
| FR-ALN-04 | エイリアンに取り返された拠点は、エイリアンの拠点に戻り、エイリアンのリスポーン地点（増援の供給源）になる |
| FR-ALN-05 | 敵拠点は、制圧するまでエリアに残り続ける（旧仕様の「破壊しても修復される」は廃止。制圧の条件は FR-ALN-08〜10）。制圧した拠点のエリアがエイリアンに取り返されると、拠点はエイリアンのものに戻る |
| FR-ALN-06 | 敵拠点の物資が減ると攻撃バリエーションが減り、牽制射撃の頻度が下がる、または牽制射撃をしなくなる |
| FR-ALN-07 | ボスとして「クイーン」が存在し、倒すとワールドクリアとなる。クイーンはワールドに1体で、ボスエリアにいる全プレイヤーが同じクイーンと戦う（体力は全員で共有する。FR-SYN-07）。クイーンの仕様は 4.4.1 のとおり（体力10万、攻撃能力なし、15秒ごとにエイリアン10体・30秒ごとに近衛兵をスポーン） |
| FR-ALN-08 | プレイヤーが拠点内のエイリアンを全滅させ、**拠点内に10秒間とどまる**と、敵拠点を制圧する |
| FR-ALN-09 | 制圧中（10秒のカウント中）は、エイリアン側の他のエリアから拠点を取り返すためにエイリアンが常にスポーンして向かってくる。制圧中にエイリアンが拠点に侵入するとカウントはリセットされ、拠点内のエイリアンを再び全滅させないとカウントは再開しない（拠点を制圧するか、あきらめるまで繰り返す） |
| FR-ALN-10 | プレイヤーが拠点の制圧をあきらめた場合、逆にエイリアンがプレイヤーを全滅させて拠点に10秒間とどまると、拠点はエイリアンに制圧される |
| FR-ALN-11 | 拠点を制圧した後は、エイリアンの無限湧きは停止する |
| FR-ALN-12 | 次の種類のエイリアンを用意する（4.4.1） |
| FR-ALN-13 | エイリアンの体力は10とし、部位ごとのダメージは次のとおりとする（4.4.2）。上級エイリアン等の軽減は 4.4.1 に従う |

#### 4.4.1 エイリアンの種類

| 種類 | 特徴 |
|---|---|
| エイリアン | 光線銃で攻撃する人型のエイリアン |
| 上級エイリアン | 光線銃に加えて手榴弾を使う。重装備で、弱点である頭にもヘルメットを装備しており即死しない。すべての部位に対するダメージが-2される（ただし、ダメージは1以下にならない） |
| タンク | 大盾を持つ人型。盾からはみ出た足を攻撃するか、手榴弾を背面に投げる。または、そのまま通り抜けて背中を攻撃すると盾を落とす |
| バルーン | 空中に浮いている人型。頭が異常に肥大化し、胴体はとても華奢。頭を攻撃すると誘爆する。プレイヤーの半径1メートル以内まで近づいて自爆する |
| スプレッダー | 腹部のみが膨張した人型。体液を周囲にまき散らして攻撃し、体液は床に3分間残る。倒されるときも自爆して周囲に体液をまき散らす |
| 近衛兵 | クイーンだけを守る人型。上級エイリアンと同等のスペック。さらに肩に自動照準の銃器を装備し、光学シールドで右半身を完全にガードしている |
| クイーン | 高さ約10mの巨体な人型エイリアン。頭が大きく発達している。**エイリアンを15秒おきに10体スポーン**させ、**30秒おきに近衛兵を呼び出す**。攻撃能力は持たない。体力は**10万**。頭への攻撃でも即死しない |

#### 4.4.2 部位ごとのダメージ

| 項目 | 値 |
|---|---|
| 体力 | 10 |
| 頭 | 10ダメージ |
| 胴 | 3ダメージ |
| 手・足 | 1ダメージ |

#### 4.4.3 世界観（裏設定）
- クイーンは他の惑星の知的生命体を捕獲して、人体実験を行っている。
- 惑星間移動ができるほどの技術力がありながら、生身のエイリアンを戦わせているのは、彼らが捕獲した知的生命体の実験体のなれの果てであり、地上に降りたクイーンの思念波で操られているためである。
- 地球も、実験体を補給するために訪れた惑星の一つとされている。
- 実験体に装備を用意するのは非効率なため、エイリアンは素朴な見た目にする。

### 4.5 資金と使い道

| ID | 要件 |
|---|---|
| FR-FND-01 | 敵を倒すと資金が得られる |
| FR-FND-02 | 資金は次の用途に使える：物資調達／援護攻撃要請／共有資金／プレイヤー強化／敵拠点攻撃要請（途中拠点の設営は行わない。リスポーン地点は制圧した敵拠点だけ。4.6） |
| FR-FND-03 | **物資調達**：弾薬・回復物資を所定の地点に置く。投入額によって物資の量が変わる。弾薬・回復物資の量は、「弾丸補給量」「体力回復量」の強化でも増える |
| FR-FND-04 | **援護攻撃要請**：上空からの爆撃（要請600）、またはタレット展開（要請300）を行う。要請の費用は固定で、攻撃量・範囲（射程）・攻撃力は強化（各5段階）で変わる |
| FR-FND-05 | **共有資金**：他プレイヤーに使い道を任せるために資金を託す。共有資金は、同じワールドの誰でも、どの用途（プレイヤー強化を含む）にも自由に使える |
| FR-FND-06 | **強化**：資金で、武器（装弾数・リロード速度・反動抑制・攻撃力）、弾丸補給量、体力回復量、援護爆撃（攻撃量・攻撃範囲・攻撃力）、タレット（攻撃量・射程・攻撃力）を、各5段階まで強化する。武器の攻撃力は、上昇が小さい（1.01〜1.5倍）代わりに、費用が最も高い（100〜10000）。体力・スタミナ・移動速度などは資金ではなくポイントで強化する（FR-PNT-03） |
| FR-FND-08 | **敵拠点攻撃要請**：敵拠点を攻撃し、増援と物資を減らす |
| FR-FND-09 | プレイヤー強化以外の用途は、他プレイヤーにも効果が及ぶ |
| FR-FND-10 | プレイヤー強化の状況は、マルチワールドをクリアした場合に限り、次のマルチワールドへ引き継がれる（ソロとは共有しない。FR-MODE-05・06） |
| FR-FND-11 | 資金は、ワールドの参加者全員へ**10秒間隔**で同期する（誰がいつ資金を提供したかは分からないため、この頻度で気付かれない想定） |

#### 4.7.1 被害者数の計算

エイリアンの進行度と経過時間から計算する。ワールド内で倒れたプレイヤーの数は、被害者数には含めず、**戦死者数**として別に数える（FR-SCR-11）。

| 項目 | 内容 |
|---|---|
| 1時間あたりの被害 | エイリアンが制圧しているノード数 × 人数（90〜130の乱数） |
| 加算 | エイリアンの制圧ノード数が5ノード増えるごとに、被害者数を1.5倍にする |
| 合計 | 経過時間（1時間ごと）の被害を合算する |

【要確認】1.5倍の適用方法（「制圧ノード数 ÷ 5」の切り捨て回数だけ1.5倍を重ねる、など）。仮置きは 機能仕様書 6.5 に記載する。

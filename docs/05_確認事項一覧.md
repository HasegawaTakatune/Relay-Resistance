## 5. 解釈で決めた事項（間違っていたら教えてほしいもの）

回答が必要というより、こちらで解釈して進めた内容。違っていれば「回答」欄に書いてほしい。

| No | 解釈した内容 | 確認したい点 |
|---|---|---|
| I-1 | 敵キル数は戦歴・勲章（撃墜章など）の判定にだけ使い、功績・ポイントには入れない | 勲章の判定にも使わないか |
| I-2 | 飛び地のエイリアンの「クイーン方向2倍」は、上流（初期スポーン側）のエイリアンが下流のプレイヤー側ノードを侵食するときに適用する。通常の最前線（下流側のエイリアンが上流のノードを侵食する向き）は1倍のまま | 通常の最前線も含めて2倍にする意図ではないか |
| I-3 | エイリアンがプレイヤーの拠点を10秒で制圧する処理は、「そのノードにプレイヤーが不在の状態で侵食が完了する」ことで代用した（サーバーは、最後の位置の更新から10秒以上たったプレイヤーを不在とみなす） | 拠点内に10秒とどまる判定を、厳密に実装するか |
| I-4 | 敵拠点の耐久値と「破壊」を廃止し、制圧（全滅＋10秒）だけにした。敵拠点攻撃要請は、物資を減らす効果だけを持つ | 攻撃要請に他の効果（増援の一時停止など）を持たせるか |

| I-6 | ソロワールドの被害者数は表示しない（ソロは侵攻しないため）。戦死者数は表示する | 被害者数もソロで表示するか |
| I-7 | 中立エリアは、出撃・ワープ先にならず、進行度・功績にも数えない。侵食の対象にはなる。最前線が届いたとき制圧扱いに昇格する | 中立エリアの扱い（ワープ先にするかなど） |
| I-8 | 1人あたりの作戦期間中ワールドの作成上限は1個、ワールド枠は100個、参加は20人まで（決定済みの内容） | 変更がなければ確定 |
